## OpenEngine 0.5.0

### Что изменилось

- Живой рендер поддерживаемых 2D-сцен Wallpaper Engine из `scene.pkg` через OpenGL 3.0.
- Слои изображения, маски, водная рябь, смещение, дрожание и эмиттеры частиц.
- Реакция на мышь — волна при клике по рабочему столу и отталкивание частиц при удержании кнопки.
- Звук сцены с настройкой громкости. Для конвертации OGG и FLAC при импорте нужен FFmpeg.
- Поиск Steam Workshop с превью, страницами и очередью импорта загруженных файлов.
- Монитор RAM, VRAM, CPU, GPU и FPS в боковой панели.
- Новый логотип и документация на русском, английском и китайском.

### Скачать

- **OpenEngine-windows-x64.zip** — готовая программа с документацией. Распакуй архив и запусти OpenEngine.exe.
- **OpenEngine.exe** — отдельный исполняемый файл Windows x64.
- **OpenEngine-source.zip** — исходники для самостоятельной сборки.

### Совместимость

Для живых импортированных сцен требуется OpenGL 3.0. Поддерживается часть формата Wallpaper Engine. Произвольные пользовательские шейдеры, SceneScript и 3D-модели пока не поддерживаются. Ранее импортированные статичные сцены нужно добавить заново из исходного пакета.

Steam может потребовать владение Wallpaper Engine и подписку на фон. В этом случае OpenEngine открывает его карточку в Steam и импортирует файлы после загрузки. Звук по умолчанию выключен.

## English

This release adds real-time rendering for supported Wallpaper Engine 2D scenes, particle simulation, cursor interaction, scene audio controls, a Steam Workshop browser, and a sidebar performance monitor.

Download **OpenEngine-windows-x64.zip** for the application and documentation. OpenGL 3.0 is required for imported live scenes. Support covers a subset of the Wallpaper Engine format. Custom shaders, SceneScript, and 3D models are currently unsupported. Reimport previously imported still scenes to use the new renderer.

Steam may require Wallpaper Engine ownership and a subscription to download an item. OpenEngine imports the files after Steam finishes downloading them.
